# Explicit action rule

Whenever Kevaro requires user-supplied information or an explicit user action, the interface must expose a visible, semantic CTA or labeled form control at the point of need.

Use direct action labels such as **Add Details**, **Enter Information**, **Register Asset**, **External Tool Handoff**, **Submit Change**, **Review**, **Approve**, or **Request Changes**. Required actions must not depend on hidden click areas, implied interaction, placeholder-only instructions, or non-interactive-looking text.

Every required control must remain keyboard accessible and expose its loading, success, failure, and unavailable states where applicable. Disabled controls must include adjacent explanatory text so users know why the action cannot currently continue.
